## Actual shared coordinate

Distance to the closed inner ellipse is convex and one-Lipschitz. Its closest-point vector supplies the actual distance gradient. Both physical height graphs use the same coordinate and their unchanged radial profiles. No independent normal or image-space correction is introduced.

For exterior points, the closest point is recovered from one nonnegative multiplier:

$$
\frac{a^2x^2}{(a^2+\lambda)^2}+\frac{b^2y^2}{(b^2+\lambda)^2}=1,
\qquad
\boldsymbol e=\left(\frac{a^2x}{a^2+\lambda},\frac{b^2y}{b^2+\lambda}\right).
$$

The existing radial derivative bounds remain valid because distance is one-Lipschitz. The monotone-front escape certificate now explicitly accepts this convex-core coordinate. Its other direction, height and regularity conditions remain unchanged. This does not certify scene radiance or later reflected transport.

Inside the ellipse, core distance and gradient are zero. The boundary-distance helper is exact outside that core and truncated deep inside it. It is not advertised as exact deep-interior signed distance.
