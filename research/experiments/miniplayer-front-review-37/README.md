## Discriminating observation

The full-height test separates reflected appearance from transmitted feature placement. Its dense source-coordinate agreement does not identify the reference geometry, but it makes a transmitted displacement explanation insufficient for the new broad contour. The actual front-normal distribution and assumed illumination remain coupled causes.

The next physical proposal should redistribute front curvature toward the perimeter while preserving a regular center. It must remain one actual height, with an optically derived back and fresh forward/source checks. Another global height or light-strength adjustment would not answer that narrower question.

A candidate can reuse the existing bevel law, matching declared central height and slope constraints rather than fitting normals independently. This is a proposal only. No exponent, amplitude or profile is selected here; fixed reference rim profiles should guide whether the question is discriminating.
