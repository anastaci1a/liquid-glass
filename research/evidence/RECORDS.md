# Record integrity

Scientific arrays, reference imagery and measured values are preserved. Each indexed object is verified against the SHA-256 of its decompressed bytes.

Text records normalize personal attribution and machine-specific paths. These editorial changes do not constitute a new experiment, score, source estimate or acceptance decision.

Existing run identifiers and case fingerprints describe the recorded experiment. They are not hashes of later editorial presentations. Earlier Git revisions retain the exact original text.

Historical reports may retain their original formatting as verbatim scientific evidence. Maintained explanations follow the [documentation standards](../../DOCUMENTATION.md).
