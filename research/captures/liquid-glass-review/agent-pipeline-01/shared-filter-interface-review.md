# Read-only shared filter interface review

Scope: current committed44225821 geometric_render.coverage_blur and root's saved blur_stage.py/candidate metadata. No new rays, source sampling, image generation, score replay, fit or code edit. This is a software/compositing contract review within the current geometry-pipeline evidence review, not an early helper blur experiment or independent acceptance of the root candidate.

PASS with limits: the shared filter computes G_sigma*(alpha*C)/G_sigma*alpha with explicit radius ceil(3sigma), leaving physical alpha unchanged. RGB outside alpha contributes zero and may remain unavailable. Sigma0 returns a copy. It is an ordinary neutral image-space material PSF approximation, not AA, refraction, dispersion or derived roughness.

The caller must supply LENS-ONLY color C, not an already coupled lens+clear image. Root blur_stage.body correctly decomposes cached per-subray actual-map samples into lens-only numerator/alpha and clear-premultiplied contribution. Compose restores alpha*C+clear; its saved zero-control asserts exactG05 equality. The fixed original foreground is applied afterward. No double-alpha edge mixture or target context is present in that code path. The helper must use this same decomposition; H1 saved integrated material is not directly the pure lens buffer required by coverage_blur.

Output support depends on actual full lens coverage/crop padding and supported lens samples, not exterior RGB invented to fill a convolution. Root code checks its finite output radius8 against lens padding and certifies all expanded source-filter rectangles before sampling. For its affine original-donor registration, checking four corners of each expanded rectangular footprint suffices for the donor rectangle because both are convex and the registration is affine. This reasoning does not extend automatically to nonlinear registrations or masks with holes. Source-kernel support and source confidence are separate from output pixel AA.

The saved native root scores and zero-control are evidence supplied by the root, NOT a new independent numerical replay by this review. Its visible candidate still needs explicit visual/source review by the final owner. Existing historical foreground/color limits, source registration assumptions and missing rim light remain. Nothing here establishes that the clear-circle blur magnitude transfers to the expanded frosted bar; only the operator and coverage/source contract transfer.
