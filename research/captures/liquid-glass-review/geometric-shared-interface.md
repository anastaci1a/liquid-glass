# Proposed shared interface — lead ownership

The initial shared core is deliberately restricted: exact primary transmission through a flat front z=0 and a concave height back z=-h(x,y), over a convex footprint, orthographic camera. Finite-camera tracing is a separate geometric extension, not claimed by this comparator.

`surface.height_gradient(x,y)` returns height, actual analytic derivatives hx/hy and inside. `surface.maximum_height` and `surface.slope_bound` are GLOBAL certificates. Height, derivatives, sections and meshes must describe ONE function. A new surface must prove concavity/convex footprint and gradient bound before using the restricted tracer; a Boolean assertion alone is not a proof.

`refract(unit_incident, unit_normal_towards_incident_medium, n_from, n_to)` returns direction/TIR/discriminant. `trace_flat_front_orthographic(surface,x,y,index,background_distance)` returns sourceXY, actual back hit, outward normal, exit ray and complete-path status. Global slope<1/sqrt(n²-1) and background gap>maximum height guarantee the transmitted branch. Concavity proves no back reentry; side exits cannot occur for the initial vertical path, and the exiting ray is below the side upon leaving the footprint. No invalid branch is assigned a fabricated background coordinate.

The circle's first family is h(r)=edge+depth*(1-u^p), u=max((r-core)/(1-core),0), r<=1, p>=3. Flat central back, C2 bevel, finite cut edge, convex back. Real parameters: core radius, sag, bevel exponent, edge thickness, n, scene distance. This replaces empirical displacement; it does not secretly retune normals.
