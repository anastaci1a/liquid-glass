# Filtering-space comparator

- Frozen input/target pixels and score masks remain unchanged. Compare decode → Gaussian/bilinear filtering → encode at the SOURCE operator, the OUTPUT Gaussian operator, and both. Remaining material, RGB directional mixture, pixel AA and reflection remain encoded-RGB; this is not complete radiometric transport. Six combinations are declared before native evaluation; no continuously fitted color-space blend.
- Source footage details.mp4 reports limited-range YUV420p, BT709 matrix/primaries/transfer via ffprobe. Its decoded RGB estimates and the video production chain do not establish the UI's working space, actual radiance or display EOTF. InverseBT709 OETF is a tested convention, not a recovered Apple pipeline.
- BT709 OETF: E=4.5L for L<.018; otherwise1.099L^.45-.099. Inverse uses threshold.081. Rounded coefficients create a tiny breakpoint inconsistency, explicitly tested rather than silently smoothed. [ITU colorimetry report](https://www.itu.int/dms_pub/itu-r/opb/rep/R-REP-BT.2380-2015-PDF-E.pdf).
- sRGB uses the standard.04045/12.92 inverse and.0031308 forward breakpoint. [W3C color conversion](https://www.w3.org/TR/css-color-4/#color-conversion-code). This alternative is motivated by [Apple's Core Image guidance](https://developer.apple.com/library/archive/documentation/GraphicsImaging/Conceptual/CoreImaging/ci_performance/ci_performance.html), which documents default light-linear filtering; it does not document Liquid Glass internals.
- Same proportional Gaussian widths, quarter-native-pixel source-kernel implementation bins, ray coordinates and border sampling as incumbent. No new precision advantage or source recoloring. Uniform inputs are preserved within transfer round-trip precision.
- Source filtering includes source Gaussian and bilinear lookup in decoded space, followed by encoding before existing gamma/material. Output-only filtering decodes the clipped shaded RGB after existing AA, applies Gaussian, then re-encodes before the existing reflection layer. Source/filter stages are not commuted.
- No adoption until original native gates, independent replay, source support and visual checks. Any adopted model must state this full operator order, not call it a generic blur setting.
