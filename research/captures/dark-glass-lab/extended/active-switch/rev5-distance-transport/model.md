# Normal transport using boundary distance

- Accepted silhouette, source, center mapping family, ordinary/dispersion kernels, lighting, shadow and masks stay fixed. Replace the displacement profile's implicit boundary coordinate and normal with true nearest-boundary distance and normal to the same crowned curve. This is an empirical inverse image map, not a recovered optical solid.
- F(x)=diag(1−core_x,1−core_y)x−a(d/r,n)n, where a uses the same seven spline coefficients and three cap coefficients; cap weight is n_major². Only the optical profile uses the new distance/normal. Existing lighting and blur transitions keep their own declared coordinates.
- All nonzero normal-profile support ends at d=.75r. Deep-interior normal ambiguity therefore has no effect on the optical displacement; profile and first two derivatives vanish there. Exterior samples use boundary normals and d=0, preserving the baseline operator convention needed by its postfilter. It is not a claim that a solid refracts outside its footprint.
- Closest points use a global 16,384-point boundary seed followed by implicit stationarity refinement. The same source-independent projection and residual checks were exercised by the previous physical-surface study. Minimum sampled radius of curvature exceeds the optical band for both observations; this is a sampled uniqueness diagnostic, not a formal global proof.
- First compare unchanged coefficients and one shared bounded linear projection of the accepted map onto this basis. The projection does not inspect target RGB. Fixed-material point-sample results are diagnostic only; native filtered images determine further work. No new pass, source epoch or public image until all original checks qualify.
