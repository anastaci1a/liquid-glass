# Interactive Liquid Glass Lab

A browser-based illustration with WebGL and software paths. It remains separate from the geometry-first reconstruction engine.

| Item | Location |
| --- | --- |
| Entry | `index.html` |
| Renderer / controls | `lab.js` |
| Shared illustrative equations | `model.js` |
| CPU fallback | `software.js` |
| Build | `npm run build` from repository root |
| Built route | `guide/site/lab.html` |

The Lab retains historical empirical options. They are not evidence that every option is an exact optical solid. Its empirical modes illustrate hypotheses; only separately verified physical models establish valid ray paths.
