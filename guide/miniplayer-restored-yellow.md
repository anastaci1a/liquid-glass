# Restored yellow hue with the thinner outline

The previous warm-yellow hue correction is restored exactly from revision 106. Full-strength input #EBCE48 again maps to #F6F586. The correction raises the green channel without changing HSV saturation or value; this explains the brighter appearance despite equal peak value.

Revision 107's thinner-left outline, 80% base width, slight brightness taper, angular gaps, body grading and artwork are unchanged. Saved outline integration is reused exactly. No geometry, optical sampling, filtering, quadrature or fitting was repeated.
